# RaCo 教師を使った多段・局所蒸留

公式 RaCo を凍結教師とし、XFeat 生徒の推論経路へ順位と中間特徴の情報を移す実験。単一 seed、固定 16 枚の合成 homography validation で A/B/C を各 1,000 成功更新比較し、C だけを継続した。ユーザー指示で学習を 4,505 更新で停止し、**validation 指標 Q が最大の 3,800 更新モデル**を最終モデルとした。

数値の正本は [集計 JSON](raco_multiscale_results.json)。[Notebook](../notebooks/raco_distillation.ipynb) で表と曲線を再描画できる。推論重みは [main の Release](https://github.com/yuki-inaho/accelerated_features/releases/tag/raco-local-kd-v1) にある。元画像、系列名、個別フレーム ID、個人のパスは公開成果物へ含めていない。

## 設計と選定

全条件で、既存の順位幾何損失、共分散の再投影 NLL、初期 XFeat 記述子の保持を使う。教師の順位出力は生徒候補上で有用性を確認できたため、候補間の順序関係を蒸留する。教師共分散は同じ候補上の幾何 NLL が初期生徒より悪かったため、今回の出力 KL は無効化した。共分散は生徒の幾何 NLL から学習する。検出枝は固定した。

B は [ReviewKD](https://arxiv.org/pdf/2104.09044) の多段整合を二尺度へ簡約した今回の設計、C は [CDS/DCDS](https://www.ecva.net/papers/eccv_2022/papers_ECCV/papers/136860001.pdf) の中間対比 head を局所幾何対応へ置き換えた今回の設計であり、各論文の学習手順をそのまま再現したものではない。[SSKD](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123540562.pdf) 型の教師補助 head は条件付き計画に留め、今回は学習していない。

| 条件 | 追加する学習専用経路 | 1,000 更新での最高 Q |
|---|---|---:|
| A | なし | 0.008210 |
| B | H/32 と H/8 の二尺度特徴整合 | 0.003149 |
| C | H/8 の局所対比 head | **0.010684** |

Q は固定 16 枚 validation の順位 utility \(U\) と共分散 NLL \(N\) から、初期値 \(U_0,N_0\) を使って

\[
Q=\min\left(\frac{U-U_0}{U_0},\frac{N_0-N}{N_0}\right)
\]

と定義した。A/B/C は同一初期 bundle、sampler seed、解像度 480×640、学習率 schedule、1,000 成功更新で比較した。B が A の Q を上回らなかったため BC を実行せず、依存する SSKD 教師補助 head と関係 KL も実行しなかった。C は 2,000、3,000、4,000 の各境界で改善傾向を再判定し、5,000 設定の途中 4,505 更新でユーザー指示により停止した。これは plateau 停止でも 5,000 更新完了でもない。

学習 checkpoint は補助 head と optimizer を含み、各 run で validation 上位 3 件と最新の再開用 1 件を保持する。推論 bundle は補助 head を除いた生徒のみで、既存 `XFeatRaCo.from_bundle()` で読み込める。3,800 更新 bundle の SHA256 は `7576862b55382f61e31fa14d68e1ef2e2be5db93a570ad7978de46427a6cf717`。

## 固定 validation と未使用 test

| 指標 | 初期生徒: validation | 3,800 更新: validation | 初期生徒: test | 3,800 更新: test |
|---|---:|---:|---:|---:|
| 順位 utility ↑ | 0.326439 | **0.401601** | 0.050836 | **0.060593** |
| descriptor TP@512 ↑ | 1,264 | **1,646** | 3,129 | **3,581** |
| 共分散 NLL ↓ | 3.494987 | **3.436685** | **3.597599** | 3.718465 |
| 50% 被覆率 | 0.546235 | 0.534609 | 0.486703 | 0.414394 |
| 90% 被覆率 | 0.897793 | 0.906571 | 0.850528 | 0.778158 |
| 95% 被覆率 | 0.943909 | 0.949291 | 0.903994 | 0.847492 |

Validation は合成 homography の固定 16 枚をフレーム等重みで集計し、8 pixel 以内の疑似対応に条件づけて NLL/被覆率を求めた。Q の最高値は **0.0166817192**。元の公開条件では 90% 被覆率の公称値からのずれも改善する必要があったが、初期生徒 **0.002207** に対して選定モデルは **0.006571** と悪化した。**ユーザーが Q 最大の 3,800 更新モデルを最終形として明示的に採用した例外**である。

モデルを validation で固定してから、未使用の実 RGB-D **144 ペア**を初期生徒と選定モデルで各一度評価した。幾何対応は双方向の深度可視性を満たす、対称再投影距離 3 native pixel 以内の相互最近傍。共分散評価は、source depth を固定した一次 Jacobian による条件付き双方向 Gaussian NLL と \(\chi^2\) 被覆率である。合成 validation と実 RGB-D test は対応と誤差の定義が異なるため、数値を直接差し引いて汎化差と解釈しない。

**test では順位と descriptor TP@512 は改善したが、共分散 NLL とすべての被覆率は悪化した。** 共分散を校正済みの不確実性として使う用途には、このモデルの出力をそのまま推奨できない。モデル forward の平均時間は初期 0.031254 秒、選定モデル 0.029931 秒/画像。8×8 位相別の幾何残差は両者で丸め誤差以内に同一（24,008 対応、全体 MSE 3.247897）であり、位置誤差の改善を示さない。

Test の 144 ペアは二つの撮影系列に由来し、同じフレームが別ペアに現れる。単一 seed とこの二系列だけでは未知シーンへの外挿、姿勢推定精度、共分散を用いた solver の改善は示せない。test によるモデル再選定は行っていない。
